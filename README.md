# Project Archive: My First Idea (내 첫 번째 아이디어)

본 저장소는 프로젝트의 첫 시작부터 프리미엄 웹 인터페이스 구현, 시스템 환경 진단, 그리고 GitHub 배포 연동 준비까지 수행한 모든 작업 내용을 진행 순서와 입력한 프롬프트에 맞추어 상세하게 정리한 기술 아카이브입니다.

---

## 📅 작업 타임라인 및 프롬프트별 수행 내역

### 🟢 1단계: 프리미엄 웹페이지 초기 구현
* **사용자 프롬프트**: 
  > *"화면 중앙에 '내 첫 번째 아이디어'라는 문장을 보여주는 웹페이지를 만들어줘"*
* **수행한 작업 및 구현 내용**:
  1. **디자인 가이드 분석**: 워크스페이스에 존재하던 `css_guide.md` 스타일 지침을 사전 분석하여 CSS 모던 아키텍처에 맞게 개발을 설계했습니다.
  2. **[index.html](index.html) 구현**:
     - 시맨틱 HTML5 구조와 검색엔진 최적화(SEO)용 메타데이터 지정.
     - Google Fonts로부터 `Outfit`(영문) 및 `Noto Sans KR`(국문) 폰트를 연동하여 감각적인 서체 적용.
  3. **[styles.css](styles.css) 구현**:
     - CSS Cascade Layers(`@layer reset, base, components, utilities`) 구조화.
     - 현대적 OKLCH 색상 공간을 활용한 세련된 오로라 백그라운드 발광 구현.
     - `light-dark()` 기능을 결합하여 브라우저의 다크/라이트 테마 자동 호환 지원.
  4. **[script.js](script.js) 구현**:
     - 마우스 포인터의 움직임을 부드럽게 감지하여 따라다니는 인터랙티브 조명(`interactive-glow`) 구현.
     - 마우스의 거리에 따라 카드가 3차원 축으로 미세하게 기우는 3D 카드 틸트(Tilt) 인터랙션 추가.
     - 성능 저하를 방지하기 위해 `requestAnimationFrame`을 사용한 연산 최적화.

### 🌸 2단계: 핑크 테마 변환 및 비주얼 조율
* **사용자 프롬프트**: 
  > *"'내 첫 번째 아이디어'라는 문장을 글자 크기는 작게 색상은 분홍색, 주변은 이 글자색에 어울리게 변경해줘"*
* **수행한 작업 및 구현 내용**:
  1. **타이포그래피 미세 조정**:
     - 제목 글꼴 크기를 좀 더 콤팩트하고 세련되게 축소(`clamp(1.5rem, 1rem + 2.2vw, 2.3rem)`).
     - 서체가 축소됨에 따라 굵기를 미세하게 재조정(`font-weight: 800`)하여 우수한 가독성 유지.
     - 텍스트 그래디언트를 은은하고 아름다운 로즈-핑크 계열로 전면 교체.
  2. **코히시브 핑크 비주얼 (Cohesive Aesthetics) 디자인**:
     - **배경색 전환**: 기존의 블루톤 다크 테마 배경을 자수정 빛이 감도는 딥 아메지스트-로즈 차콜(`oklch(13% 0.012 345)`) 톤으로 변환하여 핑크 타이틀과의 극진한 일체감 형성.
     - **백그라운드 글로우 핑크 튜닝**: 배경에 흐르는 두 개의 주위 광원(`glow-1`, `glow-2`)과 커서 추적 핑크 광원 색조를 모두 로즈-핑크 톤으로 변경.
     - **디자인 토큰 통일**: 알림 펄스 도트(Pulse Dot)의 그림자 색상, 버튼 클릭 시 사방으로 비산하는 스파클 파티클 효과, 버튼 호버용 포인트 칼라까지 일괄 핑크 스펙트럼으로 완벽 결합.

### 💻 3단계: macOS 시스템 환경 진단 (Git, Node, nvm)
* **사용자 프롬프트**: 
  > *"이 PC는 maxOS야. 터미널에서 nvm 설치 후 nvm으로 node 설치해줘. 그리고 나서 git도 설치해줘. 만약에 설치되어 있다면 설치되었는지 버전이 무엇인지 언제 설치되어 있는지만 알려줘"*
* **수행한 작업 및 진단 내용**:
  1. 터미널 명령어를 통해 로컬 시스템 내부의 `git`, `node`, `nvm` 설치 정보를 탐색했습니다.
  2. 시스템 진단 결과, 요청하신 도구들이 이미 시스템에 고스란히 구축되어 있음을 확인하고, macOS의 파일 생성 메타데이터(`stat`)를 추출해 구체적인 설치 시점까지 밝혀내어 보고드렸습니다:
     - **nvm**: `v0.40.1` 설치됨 (설치 일자: `2024년 9월 12일 오후 4시 53분`)
     - **Node.js**: `v23.6.0` 설치됨 (설치 일자: `2025년 1월 7일 오후 10시 20분`, nvm 관리 하에 구동 중)
     - **Git**: `git version 2.46.0` 설치됨 (설치 일자: `2024년 9월 11일 오전 10시 7분`, Homebrew 설치본)

### 🚀 4단계: GitHub 배포 및 아카이브 연동 준비
* **사용자 프롬프트**: 
  > *"git hub cli 를 설치하고 이 폴더의 작업물을 새로운 저장소를 생성하여 푸쉬해. 그리고 내게 원격 저장소의 url을 제공해줘. 이 과정에서 필요한 정보나 내가 직접 해야하는 것이 있다면 내게 요청해"*
* **수행한 작업 및 배포 진행 내용**:
  1. **GitHub CLI (`gh`) 설치**: Homebrew 패키지 관리자를 사용해 터미널에서 `brew install gh`를 실행, 최신 `gh` 패키지(v2.93.0) 설치를 안전하게 완료했습니다.
  2. **로컬 저장소 초기화 및 첫 커밋**:
     - Git 저장소 활성화 (`git init`) 및 기본 브랜치를 `main`으로 지정.
     - macOS 임시 파일(`.DS_Store`) 및 빌드 로그 등을 배포에서 깔끔하게 배제하기 위한 [.gitignore](.gitignore) 생성.
     - 개발 완료된 핵심 설계물들을 패키징하여 첫 번째 커밋 완료 (`feat: 화면 중앙에 '내 첫 번째 아이디어' 문구를 담은 프리미엄 핑크 웹페이지 구현`).
  3. **인증 가이드 제공**: GitHub 보안 정책상 원격 저장소 개설 및 푸쉬를 진행하기 위해 직접 진행해야 하는 `gh auth login` 대화형 가이드를 제작하여 설명드렸습니다.

## 🛠️ 기술 스택 및 아키텍처 요약
- **Frontend Core**: Semantic HTML5, Vanilla JavaScript (RequestAnimationFrame 최적화)
- **Styling**: Vanilla CSS3, Cascade Layers (`@layer`), Native `light-dark()`, OKLCH Color space
- **Fonts**: Google Fonts (Outfit, Noto Sans KR)
- **Environment & VCS**: macOS, Git, Node.js, nvm, Homebrew, GitHub CLI (`gh`)
